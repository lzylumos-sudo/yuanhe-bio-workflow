Historical project audit: 2026-10-17, integration candidate 0.2

The external folder contained the main modules and both model weights, but was not then a completely connected, portable, validated system. The audit repaired confirmed defects and added the first unified stage interface. It did not execute formal target inference, docking, screening or dynamics.

Correct workflow: complex review -> full receptor plus local pocket -> Peptide2Mol seeds -> reviewed molecular cores -> REINVENT4/LibInvent expansion -> unique chemistry/conformers -> GNINA with the peptide-removed full receptor -> ZVSS -> candidates -> membrane GROMACS -> analysis. The target was subsequently confirmed as MurJ. REINVENT4 expands a molecular core, not a protein backbone; GNINA is the actual docking tool.

Repairs covered Hydra Unicode/space quoting and random seeds; reused output contamination and empty-success handling; actual source fingerprints and upstream commit checks; mapped-core identity comparisons; disconnected/stereochemical candidates; cropped-pocket/full-receptor confusion; upstream artifact hashes; cancellation parameters; symlink/path traversal; origin/Host/body checks; log cursors; serialized shared outputs; screening cache content/source validation; and archival isolation of old rule-generated molecules.

Inventory: 12,781 non-runtime entries, including 7,641 Python files, many third-party; no AST errors. This was not a line-by-line audit of all dependencies. Weights and binary images were not treated as executable source evidence.
Historical tests: generation 57 passed; docking 17 passed/1 skipped; ZLIS 40 passed with a NumPy compatibility warning; screening 24 passed/3 skipped/3 integration deselected; standalone OpenMM contracts 61 passed; workflow/HTTP guards 15 passed. Adapter doubles were not real inference. Browser checks observed actual structure atoms and configuration behavior without target computation.

Cleanup removed 435 cache/duplicate/runtime-export entries, about 13.12 GiB logical or 29.33 GiB allocated on exFAT. Allocated project space decreased from about 53.18 to 23.83 GiB before small new additions. Removed items included an old WSL tar, nonportable old venvs, test copies, obsolete backups, caches and metadata. Active VHDX, weights, source, important results and the OpenMM offline package were retained. No formatting, driver changes or WSL unregistration occurred.

At that revision GROMACS only accepted an external prepared TPR, with membrane construction and full trajectory analysis still pending. Those functions were added later in 0.3.0-rc1; their target-machine execution remains untested. Outstanding acceptance includes installed target environments, real small-batch inference/docking/screening, second-host migration, scientific input review, membrane parameterization and replica analysis. Engineering checks do not prove synthesis feasibility, pharmacophore preservation or biological activity.

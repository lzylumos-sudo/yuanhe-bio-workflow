# 课堂报告检查项

以真实 run 的自动 HTML 报告为基础填写观察，不填造实验活性或截图结论。

1. 环境与硬件：doctor、软件锁文件、实际引擎/模型/设备。
2. 受体：1DRF 来源、链 A、FOL A:187；准备策略、缺失原子补全记录。
3. 盒子：坐标来源、参考哈希、center/size、每侧 padding 与包含测试。
4. 库与准备：原始名称/SMILES、内部 ID、状态、构象、失败原因。
5. 搜索：真实 seed、exhaustiveness、num_modes、CPU/超时参数。
6. 结果：成功/失败数量、母体 Top10、各层 CSV 与实际命令日志。
7. 姿态：至少两张不同实际 pose 图片，记录对应 pose ID。
8. 局限：演示库无标签、未评价富集；分数/单位含义；参考重对接表现与局限。
9. 引用：docs/references.bib 与实际使用版本。

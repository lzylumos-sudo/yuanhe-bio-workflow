# 科研筛选指南

## 受体

上传 PDB/mmCIF 或已准备的 PDBQT。先选择作者链和模型，阅读计划中的非蛋白组分、altloc、断链、金属和非标准残基。手动决定保留的水、离子和辅因子。默认科研计划不替用户删除全部 HETATM。

准备策略中的 `keep_hetero` 使用作者编号，例如 `A:201`。`altloc` 选择需要保留的替代构象。只有显式 `repair_missing_sidechains=true` 才补全缺失原子；不重建缺失 loop。`residue_templates` 可传 Meeko 实际支持的映射，例如 `A:17=HID`。Meeko 模板加氢并不代表确定了 pH 7.4 的精确微观状态。

盒子支持人工 center/size、真实参考配体 SDF 或 `pocket_residues` 列表。size 为完整边长，单位 Å。参考配体坐标不重新嵌入。确认准备后，在受体和盒子预览里检查覆盖区域，再勾选确认才能提交科研任务。外部 PDBQT 需提供对应准备 PDB，质子化来源标为 external/unknown。

## 协议与状态

`research_gnina` 使用刚性受体、empirical vina、CNN rescore、固定内置模型 `crossdock_default2018_1_3`、exhaustiveness 16、9 poses、seed 20261012。硬件自动选择已真实验证的 GPU 或 CPU CNN；不会切换到独立 Vina 或关闭 CNN。

默认 `ligand_states: preserve`。显式枚举可在搜索参数 JSON 中设置：

```json
{"ligand_states":"enumerate","ph_low":6.4,"ph_high":8.4,"max_states":8,"fragment_policy":"reject"}
```

使用固定 Molscrub 0.2.2 酸碱与互变异构规则。状态按规范异构 SMILES 去重、稳定排序并截断，截断不代表人口占比排名。盐/多片段默认拒绝；显式 `fragment_policy: largest` 才选最大片段。未知手性保持警告，不伪称已确定。每个状态单独保存化学身份与生成策略。

`research_refine` 表示多 seed **重新 docking**：最多生成 8 个输入构象，ETKDGv3 的 0.5 Å 去重，按 MMFF（必要时 UFF）优化能保留最多 3 个；seed 11/23/47、exhaustiveness 32。输入构象能不是结合能。

母体汇总：每个状态、每个 seed，在全部输入构象输出中选代表 pose；Vina 按 affinity，GNINA 按 CNN pose score。随后对 seed 代表分数取中位数；母体默认选状态中最优的中位数。所有状态和 seed 原始分数仍保留。页面可切换已有母体代表的分数排序，原始 ranking.csv 不被覆盖。

## 两阶段与导出

结果页面的“下一阶段 GNINA”支持指定 TopK。score_only 使用已有同坐标系 pose；redock 重新生成输入构象并实际搜索；refinement 使用 minimize，可能改变坐标，输入姿态始终保留。CLI 使用相同核心函数。

每个新 run 保存受体/盒子快照、原始输入、展开配置、软件哈希、逐配体命令、日志、状态与结果。已完成条目只有完整文件校验通过才能续用。不同引擎、模型、状态、盒子或 seed 的旧排名不会被混用。

手工选择 MD 交付姿态时需勾选审查并填写审查人。SDF 是化学主文件；PDB 只是同坐标系预览。未做力场参数化、溶剂化、MD 或自由能计算。

## 当前边界

共价对接、未经验证的金属配位、复杂辅因子参数化、柔性受体/柔性侧链、缺失长 loop 重建未作为可用科研功能开放。不支持 MOL2 作为可靠输入路径，优先使用经核查的 SDF。没有靶点活性标签，尚未评估 ROC-AUC/PR-AUC/EF 或筛选富集性能。单个 FOL 重对接不代表本靶点普适筛选性能。

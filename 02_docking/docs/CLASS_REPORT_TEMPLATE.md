# Classroom report checklist

Base observations on the actual run's generated HTML report. Do not invent activity labels or visual conclusions.

1. Environment: versions, locks, engine, CNN model and actual device.
2. Receptor: 1DRF source, chain A, FOL A:187, preparation policy and atom repairs.
3. Box: coordinate source/hash, center, full side lengths, padding and containment.
4. Library: names, SMILES, internal IDs, states, conformers and failures.
5. Search: actual seeds, exhaustiveness, modes, CPU and timeout.
6. Results: success/failure counts, parent top ten, CSV and command logs.
7. Poses: at least two distinct actual images with pose IDs.
8. Limits: unlabeled demonstration library, no enrichment evaluation, score units and redocking scope.
9. References: references.bib and actual software versions.

# 使用指南

## 课堂快捷入口

1. 双击根目录 `START_WINDOWS.cmd`，访问 `http://localhost:5902/`。
2. 输入 `CCO` 或多行 `SMILES 名称`，点击“开始筛选”。没有名称会自动分配内部 ID；重复名称不会覆盖文件。
3. 页面显示实际状态、成功/失败数量和数值结果。点击排名行切换母体代表姿态，通过 pose 下拉框查看其它输出姿态。
4. 打开盒子和口袋残基标签检查空间位置；“保存当前姿态 PNG”将真实 WebGL 视图保存到本次 run 的 images 目录。
5. 下载 ranking.csv、poses.csv、states.csv、failures.csv、manifest 或 HTML 报告。至少保存两张不同实际姿态图后，再导出完整课堂报告。

完整课堂入口选择 `data/demo/ligands_20.smi`。100 分子库为 `data/demo/ligands_100.smi`，同样可上传。它们是流程演示库，没有活性标签，不是 DHFR 抑制剂库。

## PowerShell 与 CLI

在当前项目根目录打开 PowerShell：`powershell -ExecutionPolicy Bypass -File .\SBVS.ps1 doctor`。`SBVS.ps1` 后接与 Linux CLI 相同的命令参数。

进入本项目专用 WSL 并位于当前项目目录后，可以运行：

```bash
./run.sh doctor
./run.sh demo --preset class_quick
./run.sh demo --preset class_full
./run.sh serve --host 127.0.0.1 --port 5902
./run.sh prepare-receptor --input data/raw/1DRF.pdb --chains A --out data/prepared/my_review
./run.sh prepare-ligands --input data/demo/ligands_20.smi --out data/prepared/my_ligands
./run.sh make-box --reference data/reference/FOL_crystal.sdf --padding 5 --out data/prepared/my_box.json
./run.sh screen --config class_quick --ligands data/demo/cco.smi
./run.sh report --run runs/本次ID
./run.sh resume --run runs/本次ID
./run.sh rescore --run runs/本次ID --engine gnina --operation score_only --top-k 10 --device gpu
./run.sh export-md --run runs/本次ID --selection data/人工选择.json
```

`runs/本次ID` 等为需要替换的占位参数，不是现有目录。科研 `prepare-receptor` 首次生成计划后会返回 REVIEW_REQUIRED；审查后把计划的 input_sha256 与 confirmed=true 写入策略 JSON，通过 `--policy` 指定。课堂内置案例的 `--classroom` 只用于明确的教学修复策略。

所有分数以 CSV 与原始输出为准。Vina 数值越负优先；GNINA 的 empirical score、CNN pose score 和 CNN affinity 分别显示，后者单位为 pK。多个 seed 先分别保留，再取各 seed 代表分数的中位数；显示的代表姿态始终是真实某条输出，不存在“中位坐标姿态”。

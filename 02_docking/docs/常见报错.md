# 常见报错

- **5902 已占用**：启动器显示占用信息。先确认是不是本项目 UUID；不会自动杀进程。显式 `START_WINDOWS.ps1 -Port 其他端口` 可选择其它端口，课堂验收仍使用 5902。
- **WSL E_ACCESSDENIED**：宿主权限或安全策略阻止访问；不应因此改用用户现有 Ubuntu。
- **GNINA 缺 libcudnn.so.9 / CUDA 12 库**：先查看 logs/install，专用环境已通过 `scripts/gnina_dependencies.sh` 安装固定用户态库；不安装 Linux NVIDIA 驱动。使用项目 run.sh 可自动设置受控库路径。
- **模型名无效**：以本项目保存的 GNINA help 和预设为准。该版本没有 `default1.3` 别名；当前锁定实际支持的 crossdock_default2018_1_3。早期失败 run 保留，未冒充通过。
- **Meeko No template matched**：检查准备日志及缺失原子/非标准残基，不能删除坏残基掩盖错误。1DRF 教学受体已明确补全缺失原子，不重建 loop。
- **INVALID_SMILES / UNSUPPORTED_ELEMENT**：失败条目进入 failures.csv，其它有效分子仍继续。
- **REVIEW_REQUIRED**：科研受体需要确认准备计划的 hash 和策略；这不是课堂快捷入口的限制。
- **Protocol/environment changed**：不能把不匹配的旧结果当续跑缓存。使用保存的输入/参数创建新 run。
- **GNINA device not verified**：迁移/硬件变化后需重新实测 CNN。显卡检测成功并不能替代这个步骤。
- **not_tested / blocked**：不是 passed。科学标签、第二台电脑、未支持体系的边界见验收报告。

- **老师案例 HTTP 401**：宿主限时请求能够连接，但需要平台认证。未读取案例内容；本项目不借用该后端计算。

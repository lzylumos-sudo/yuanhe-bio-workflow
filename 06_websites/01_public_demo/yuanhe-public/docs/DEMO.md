# 3 分钟演示操作

1. 首页介绍结构驱动、证据可溯的研究路径；点 EN 可切英文。
2. 进入工作台，点“加载公开结构”。拖动旋转、滚轮或按钮缩放，链选择查看 MurJ 或 SglM；“结合区域”聚焦多肽。
3. 调整接触阈值 3.5 / 4 / 5 / 6 / 8 Å，搜索残基、切换排序，点击“定位”在三维中高亮残基。下载当前 CSV。
4. 逐步浏览生成、优化、对接、筛选和 MD。参数为界面示意，页面明确提示没有公开样例，不会运行私有模型。不要向评委描述为已计算完成。
5. 打开研究报告，打印 / 保存 PDF，或下载 JSON 证据。报告包含来源、结构限制、当前接触筛选和未提供的阶段。
6. 合作页可下载研究需求草稿；正式邮箱待项目方提供，目前不会发送内容。

无 WebGL 时查看结构静态图、下载 PDB 和接触表。若 JSON 读取失败，页面提示刷新；无需连接科研后端。
